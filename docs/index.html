Mucc C Compiler

News

[October 1, 2026: Mucc 1.1.0 released. On main since then, for the next release: -g debug info, __int128, _Complex, SSE vector types and intrinsics, K&R function definitions, objects of 2 GiB and more, and releases built by mucc itself, with no gcc. See the changelog.]

Features

  • ONE FILE! The compiler, preprocessor, assembler, linker, headers and C library (musl) are one static program of about 8.5 MB. Copy it onto any x86-64 Linux machine, an empty container or a USB stick, and build C programs with nothing else installed: no gcc, no binutils, no system headers.
  • FAST! It compiles, assembles and links about 2.7 times faster than gcc -O0.
  • REAL C! C17 by default, C23 with -std=c23, and the GNU extensions real code uses. SQLite, CPython, Git, redis, Lua, jq, GNU make, sed, gawk and TinyCC build with it and pass their own test suites. Mucc of course compiles itself, byte for byte.
  • DEBUGGABLE! -g lets gdb show variables, types and lines, and -Wall, -Werror and -Wno-name work as with gcc.
  • BUILT BY ITSELF! From the next release on, each release is compiled, assembled and linked by the one before it, with gcc and binutils nowhere in sight.
  • SMALL! About 27,000 lines of C, in sections, that one person can read from end to end.
  • It takes gcc's flags (-c, -S, -E, -o, -I, -D, -l, -std= and the rest), so build scripts work unchanged. Like clang, it says it is gcc 4.2.

Compilation Speed

Compilation speed for mucc's own source. There are 26,713 lines; 49,159 lines (1.7 MBytes) are compiled because the same headers are included in many files. Mucc is about 2.7 times faster than GCC -O0.

CompilerTime(s)lines/secondMBytes/second
Mucc (main)0.441120003.9
GCC 15.2 -O01.18415001.4
GCC 15.2 -O25.1396000.33

Measures were done on an AMD Ryzen 5 7600X under WSL 2, one file at a time, best of 7. Real time is measured. Compilation time includes compilation and assembly. Code that mucc generates runs about as fast as code from gcc -O0: for the fastest programs, use gcc or clang.

Download

The latest release is at github.com/Dom-Yan/Mucc/releases/latest. To install it on any x86-64 Linux (Ubuntu, Debian, Fedora, Arch, Alpine, WSL 2 and others):

mkdir -p ~/.local/bin
curl -Lo ~/.local/bin/mucc https://github.com/Dom-Yan/Mucc/releases/latest/download/mucc-x86_64-linux
chmod +x ~/.local/bin/mucc
mucc -o hello hello.c && ./hello

Programs are linked statically against the musl inside mucc, so they run on any x86-64 Linux. To use the system's glibc and shared libraries instead, add --libc=system. Building mucc from source, with only mucc, is explained in the README.

What it doesn't do

  • Run anywhere but 64-bit Intel or AMD Linux (on Windows, WSL 2), or make programs for anything else.
  • Optimize: use gcc or clang where performance is crucial.
  • C++, _BitInt, AVX and later vector instructions, or shared libraries without --libc=system.

You want to help ?

Here are some suggestions:

  • Report bugs on the issue tracker, with a small C file that shows the problem (and eventually fix them).
  • Send fixes as pull requests. Run make test-all first, add a test for each fix, and make sure you have read and understood every line you send.
