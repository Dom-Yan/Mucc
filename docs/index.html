Mucc

Mucc is a small, self-hosting C compiler for x86-64 Linux, written in C. It turns C source into a running program with its own preprocessor, parser, code generator, assembler and linker, in about 18,000 lines of code.

It comes as one static binary of about 7 MB with its headers and C library (musl) inside it, so it needs nothing else installed: no gcc, no binutils, no glibc, no system headers.

It aims to be minimal, easy to read and fast to compile with. It is not trying to replace gcc or clang.

What it does

  • Compiles C17 by default, and most of C23 with -std=c23
  • Compiles itself, and the result compiles itself byte for byte the same
  • Builds CPython, Git, SQLite, Lua and zlib, which pass their own tests
  • Compiles about 4.5 times faster than gcc -O0, and 17 times faster than gcc -O2

Try it

curl -LO https://github.com/Dom-Yan/Mucc/releases/latest/download/mucc-x86_64-linux
chmod +x mucc-x86_64-linux
./mucc-x86_64-linux -o hello hello.c
./hello

Where it runs

The binary runs on any Linux on 64-bit Intel and AMD (x86-64) machines, with glibc or musl, new or old, including WSL 2 on Windows and empty containers. The programs it builds are static, so they run on any x86-64 Linux machine too. It does not run on macOS or ARM.

Mucc 1.0 is feature complete. What remains is speed, performance, bug fixes, and new features only when the C language changes.
