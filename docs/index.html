The Mucc C Compiler

Mucc is a small, fast, self-hosting C compiler toolchain for x86-64 and ARM64 Linux. The compiler, preprocessor, assembler, linker, archiver, headers and C library are one static file of about 3 MB. Copy it onto any 64-bit Linux machine, an empty container or a USB stick, and it builds working C programs with nothing else installed: no gcc, no binutils, no system headers.

curl -Lo mucc https://github.com/Dom-Yan/Mucc/releases/latest/download/mucc-$(uname -m)-linux
chmod +x mucc
./mucc -o hello hello.c && ./hello

What Makes Mucc Different¶

  • One file is the whole toolchain. Most compilers need a separate assembler and linker (binutils), and the system's C library and headers. Mucc carries its own of each: its assembler, its linker, its archiver (mucc -ar), musl, and musl's and Linux's headers, compressed inside the binary and read from memory.
  • Programs that run anywhere. By default it links statically against its own musl, so what it builds runs on any Linux for that CPU, old or new, glibc or not.
  • Fully self-hosted. Each release is compiled, assembled and linked by the one before it, with gcc and binutils made to fail so nothing else can take part, and it rebuilds itself to the same bytes. No other compiler is needed, ever, to build or use mucc.
  • Fast to compile. About 4 times faster than gcc -O0 and 2 times faster than clang -O0.
  • Two CPUs, either way. It runs on x86-64 and ARM64 and makes programs for both: --target=aarch64-linux on an x86-64 machine, or the other way round.
  • Small enough to read. About 35,000 lines of C in 16 files, split into sections, that one person can read from end to end.
  • Real C, for real programs. C17 by default, C23 with -std=c23, and the GNU extensions real code uses. SQLite, Lua, Redis, Tcl, jq, zlib, Git, libpng, QuickJS and TinyCC build with it and pass their own test suites; CPython passes 402 of its 408.
  • A drop-in for gcc. It takes gcc's flags, so Makefiles and configure scripts work unchanged. Like clang, it says it is gcc 4.2.
  • Debuggable. -g writes DWARF that gdb understands, and errors point at the line and column like gcc's.

What It Doesn't Do¶

Use gcc or clang if you need any of these:

  • Platforms other than 64-bit Intel, AMD or ARM Linux (on Windows, use WSL 2).
  • Optimization beyond register allocation and constant folding: its code is in the range of gcc -O0's.
  • C++. Mucc compiles C only.
  • Shared libraries and dlopen with the bundled musl: use --libc=system for those.
  • Sanitizers, coverage or profiling.
