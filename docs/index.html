Mucc

Mucc is a small, self-hosting C23 compiler for x86-64 Linux, written in C. It turns C source into a running program with its own preprocessor, parser, code generator, assembler and linker, in about 15,000 lines of code.

It aims to be minimal, easy to read and fast to compile with. It is not trying to replace gcc or clang.

What it does

  • Compiles C11 and most of C23
  • Compiles itself, and the result compiles itself byte for byte the same
  • Builds SQLite, Lua and zlib, which pass their own tests
  • Compiles about 3.6 times faster than gcc -O0

Try it

git clone https://github.com/Dom-Yan/Mucc.git mucc
cd mucc
make
./mucc -o hello hello.c

Where it runs

The compiler runs on Linux with glibc on 64-bit Intel and AMD (x86-64) machines, including WSL 2 on Windows. The programs it builds run on any x86-64 Linux machine, and with -static they don't even need glibc. It does not run on macOS or ARM.

Mucc is feature complete. What remains is speed, performance, bug fixes, and new features only when the C language changes.
