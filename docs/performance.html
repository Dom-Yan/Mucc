Performance

Mucc is built to compile fast. The numbers on this page were measured in October 2026; make bench measures them again, on your own machine (see How the Numbers Were Measured). The mucc measured is the release binary, which mucc built, as the one you download is. (A mucc built by gcc -O2 compiles about 1.9 times as fast again, as the last table shows.)

How Fast Mucc's Code Runs¶

Mucc itself as the program: mucc built four ways, each compiling the same source.

Mucc built byTimeSlower than gcc -O2 by
gcc -O20.24 s
gcc -O00.36 s1.5x
mucc, with glibc (--libc=system)0.37 s1.5x
mucc, with its musl (the default)0.45 s1.9x

So the code mucc makes runs about as fast as gcc -O0's. The bundled musl's malloc and stdio make programs about 1.2 times slower than with glibc. For the fastest programs, build with gcc or clang at -O2.

How the Numbers Were Measured¶

On an Intel Core i7-1185G7 laptop under WSL 2, with gcc 15.2, clang 21.1 and tcc 0.9.27: real time, best of 7 with the compilers taking turns, one file at a time. Compilation time includes compilation and assembly.

Your numbers will differ. Measure them on your own machine with:

make bench                                  # mucc's own source
make bench SQLITE3_C=path/to/sqlite3.c      # and SQLite's amalgamation

Download the amalgamation from sqlite.org. test/bench.sh measures clang and tcc too if they're installed.

Why It's Fast¶

  • One process, no pipes. The preprocessor, compiler, assembler and linker run in one program, passing text and objects in memory.
  • Simple, linear passes. Each stage reads its input once. There is no intermediate representation to optimize over.
  • Tuned where the time goes. Tokens hash their names once, the tokenizer and assembler look characters up in tables, assembly lines are written straight into one buffer, and memory comes from an arena in huge pages.
  • Code that runs fast enough. Constants are folded, instructions take constants, variables and members as operands in place, and arguments go straight into registers: mucc compiles its own code, so better code makes mucc faster too.
